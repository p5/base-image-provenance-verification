A reference makes the connection.

The build records the base digest in a new statement. The provider signature stays with the base.

Keep this distinction

The customer statement contains the base reference. It does not contain the provider signature.

02

Two signatures. Two independent checks.

A user starts with BBB, reads the verified base reference, and retrieves the provider evidence separately.

Where trust enters

Users approve the workflow and the provider keys. A signature authenticates a statement; the builder must tell the truth.
